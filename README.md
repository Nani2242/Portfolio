# GudiPortfolio
ASP.NET Core 8 portfolio using MVC Controllers + Views and Razor Pages in one project.

## Requirements
- .NET 8 SDK
- Visual Studio 2022 (17.8+) or VS Code

## Run locally
1. Extract the ZIP.
2. Open a terminal in the project folder.
3. Run `dotnet restore` and then `dotnet run`.
4. Open the localhost URL printed in the terminal.

## Routes
- `/` — MVC Home
- `/Home/About` — MVC About page
- `/Projects` — Razor Page
- `/Contact` — Razor Page

## Before publishing
Verify dates, project descriptions, phone, email and LinkedIn URL. Add your resume file and a download link if desired. Never publish client secrets, customer data, API credentials or proprietary code.

Contact currently uses mailto links and does not save messages in a database.
